# kgraphing

## A collection of utilities for working with knowledge graphs.

This library seeks to provide a set of utility functions to enable the 
ingestion, management, visualisation and analysis of knowledge graph content
expressed in the W3C RDF standard.

### Ingestion

Work with mappings to convert flat or nested data into fully marked-up RDF graphs.

### Enrichment

Leverage W3C standards to fetch distributed ontologies and definitions to annotate
and enrich your knowledge graph.

### Storage and Management

Load, manage and combine content across named graphs in an RDF store.

### Analysis

Query and analyse the contents of graphs, run validation tasks with SHACL and 
make use of RDF reasoners and inference engines. 

Run common high level analyses over knowledge graphs to extract shape and structural
information.

### Visualisation

Generate rich, meaningful visualisations of complex data relationships in an open
flexible style.

### Installation

Install kgraphing using pip, or your favourite package manager. The command from pip is:

`pip install kgraphing`
